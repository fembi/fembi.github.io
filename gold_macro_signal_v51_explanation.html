Penjelasan Lengkap GOLD MACRO SIGNAL v5.1 ALMA+KNN

Dokumen ini menjelaskan fungsi setiap fitur utama pada script Pine gold_macro_signal. Indikator ini dibuat untuk membaca bias XAUUSD/GOLD, terutama pada timeframe M5, dengan kombinasi macro driver, trend multi-timeframe, smart money concept, KNN gate, dashboard, dan risk level otomatis.

Gambaran Umum

GOLD MACRO SIGNAL v5.1 ALMA+KNN adalah indikator overlay TradingView Pine Script v6. Script ini tidak membuka posisi otomatis, tetapi memberi sinyal visual BUY/SELL, level entry, stop loss, take profit, status market, dan alasan entry melalui dashboard.

Market utama XAUUSD/GOLD, paling cocok dipakai di M5 sesuai komentar script.
Model utama Macro driver + trend filter + trigger price action + quality score.
Fitur tambahan AI KNN gate, OB/FVG, liquidity sweep, killzone, risk plan, dashboard.
Indikator ini adalah alat bantu analisis, bukan jaminan profit. Semua sinyal tetap perlu dikombinasikan dengan manajemen risiko, spread, kondisi news, dan disiplin eksekusi.

Alur Kerja Sinyal

  1. Script membaca kondisi makro dari DXY, US02Y, dan US10Y, lalu mengubahnya menjadi Macro Score. Nilai positif berarti bullish untuk emas, nilai negatif berarti bearish untuk emas.
  2. Script membaca trend besar dari H1 dan H4 memakai EMA 50/200. Filter ini dipakai untuk memastikan sinyal tidak melawan arah institusional kecuali macro score sangat kuat.
  3. Script membaca trend M5 sebagai anchor dengan MA pilihan pengguna: EMA, ALMA, atau HMA. Default-nya ALMA.
  4. Script membaca tape cepat M1 untuk melihat apakah gerakan mikro sudah searah dengan rencana BUY atau SELL.
  5. Script mencari trigger entry: liquidity sweep, BOS, VWAP cross, MA cross, pullback, FVG mitigation, OB mitigation, PDH/PDL/PWH/PWL sweep, atau Asia range sweep.
  6. Script menghitung Signal Quality dari macro, HTF, tape, trigger, volume/displacement, session, dan confluence OB/FVG.
  7. Jika KNN mode aktif dan sample sudah cukup, script mengecek apakah kondisi sekarang mirip dengan trade historis yang bagus atau buruk.
  8. Jika semua filter lolos, muncul sinyal BUY/SELL, label entry, SL, TP1, TP2, TP3, serta alasan entry pada dashboard.
Contoh alur sederhana

Misalnya DXY turun kuat, US02Y turun, dan US10Y turun. Karena ketiga driver ini biasanya berlawanan arah dengan emas, Macro Score menjadi positif. Jika H1/H4 juga bullish, M5 berada di atas MA dan VWAP, lalu muncul sweep low yang close kembali naik, script bisa menganggap itu sebagai kandidat BUY. Setelah quality, KNN, cooldown, dan candle close lolos, barulah label BUY muncul.

Contoh Pembacaan Macro Score

Macro score adalah fondasi arah. Script membalik efek DXY dan yield terhadap emas, sehingga pelemahan DXY/yield cenderung menjadi nilai bullish untuk gold.

Kondisi Driver Dampak ke Gold Kemungkinan Dashboard

DXY turun, tetapi yield naik kuat Campuran, bisa netral atau lemah HANYA MACRO, PARTIAL ALIGN, atau NEUTRAL

Jika dynamic threshold saat itu 22, maka Macro Score +50 sudah melewati threshold dan dianggap bullish. Tetapi sinyal BUY tetap belum boleh muncul sebelum HTF, M5/M1 tape, trigger, quality, dan KNN ikut lolos.

Logika BUY dan SELL

BUY Signal

Sinyal BUY membutuhkan kombinasi kondisi berikut:

  • Data macro siap.
  • macroScore berada di atas dynamic threshold.
  • HTF bullish atau macro override cukup kuat.
  • M5/M1 tape mendukung arah bullish.
  • Ada trigger valid seperti sweep buy, BOS buy, VWAP/EMA cross up, pullback, OB/FVG mitigation, atau liquidity support sweep.
  • Tidak sedang exhausted di Keltner upper.
  • Tidak ada bearish fakeout divergence.
  • Tidak diblok oleh KNN active gate.
  • Cooldown selesai dan candle sudah close jika signalOnClose aktif.

SELL Signal

Sinyal SELL adalah kebalikan dari BUY:

  • macroScore berada di bawah negatif dynamic threshold.
  • HTF bearish atau macro override bearish cukup kuat.
  • M5/M1 tape mendukung bearish.
  • Ada trigger valid seperti sweep sell, BOS sell, VWAP/EMA cross down, pullback, OB/FVG mitigation, atau liquidity resistance sweep.
  • Tidak sedang exhausted di Keltner lower.
  • Tidak ada bullish fakeout divergence.
  • Tidak diblok oleh KNN active gate.

Contoh Skenario Entry

Contoh BUY valid

Macro Score +48 Threshold 22 HTF Bull M5 di atas VWAP M1 Bull

Harga sweep PDL, lalu close kembali di atas PDL dengan candle bullish. Ada volume spike dan tidak sedang menyentuh KC upper. Dashboard bisa menampilkan SETUP READY BUY, BUY SIGNAL B+, atau BUY ARMED sebelum candle close.

Fungsi praktisnya: trader menunggu candle close, melihat entry/SL/TP yang digambar, lalu mengecek apakah spread dan news masih aman.

Contoh SELL valid

Macro Score -52 HTF Bear M5 di bawah VWAP M1 Bear PDH Sweep

Harga mengambil likuiditas di atas PDH, lalu close kembali di bawah PDH. Delta melemah dan candle bearish cukup besar. Jika quality lolos dan KNN tidak block, label SELL muncul dengan grade seperti B+ atau A.

Fungsi praktisnya: PDH sweep menjadi trigger, macro/HTF menjadi filter, dan risk line memberi batas invalidasi.

Contoh no-trade karena konflik

Macro Bull HTF Bear M5 Mixed Trigger ada

Walaupun ada sweep low, dashboard bisa menampilkan HTF counter-trend atau KONFLIK HTF. Artinya trigger ada, tetapi arah besar belum mendukung.

Contoh no-trade karena exhausted

Macro Bull HTF Bull Harga di KC Upper

BUY bisa dibatalkan karena harga sudah terlalu jauh naik. Dashboard akan memberi alasan seperti Exhausted (Harga di KC Upper). Fungsi filter ini adalah menghindari entry di area yang sudah terlalu mahal.

Penjelasan AI KNN Engine

KNN pada script ini bukan AI cloud atau machine learning eksternal. Ia adalah sistem nearest-neighbor lokal di Pine Script. Setiap trade yang selesai akan disimpan sebagai sample, lalu kondisi saat ini dibandingkan dengan sample lama yang paling mirip.

Mode Fungsi
Off KNN tidak dipakai untuk display maupun filter sinyal.
Advisory Only KNN hanya tampil di dashboard sebagai informasi, tidak memblok sinyal.
Active Gate Jika sample sudah mencapai batas minimal, KNN boleh memblok sinyal dengan win rate rendah.

KNN memakai 8 fitur: macro score, ATR percent volatility, jam trading, HTF score, RSI, signal strength, order flow score, dan market regime. Hasilnya berupa win rate, expected R, jarak rata-rata neighbor, dan grade AI.

Saat sample masih kecil, status KNN akan berada di fase learning/advisory. Setelah sample cukup, barulah Active Gate benar-benar relevan.

Contoh KNN dalam Praktik

Kondisi Contoh Tampilan Arti
Sample masih sedikit AI LEARNING 18/30 KNN belum cukup data. Jangan terlalu mengandalkan grade AI.
Sample belum mencapai active gate AI B ADV 55/80 KNN memberi informasi, tetapi belum memblok sinyal.
Sample cukup dan win rate rendah AI D BLOCK Sinyal bisa diblok karena kondisi mirip historisnya buruk.
Sample cukup dan win rate tinggi AI A BOOST Signal Quality ditambah karena kondisi mirip historisnya bagus.
Contoh KNN block

Misalnya setup SELL muncul saat macro bearish, tetapi KNN menemukan 11 tetangga historis yang mirip: mayoritas trade serupa gagal atau expected R negatif. Jika knnWinRate hanya 32% dan knnBlockThreshold 35%, dashboard menulis KNN BLOCK 32%. Walaupun trigger teknikal terlihat valid, sinyal akhir bisa tidak keluar.

Contoh KNN boost

Jika kondisi BUY mirip dengan sample historis yang sering mencapai TP, misalnya KNN win rate 74% dan threshold boost 70%, script menambah kualitas sinyal sebesar knnBoostAmount. Setup yang tadinya grade B+ bisa naik mendekati A.

Risk Management Otomatis

Setelah sinyal muncul, script membuat rencana risiko otomatis:

  • Entry: memakai harga close anchor saat sinyal.
  • Stop Loss: berbasis swing lokal dan ATR buffer.
  • TP1: target pertama berbasis R multiple.
  • TP2: target kedua berbasis R multiple.
  • TP3: target akhir berbasis R multiple.

Jika macro score kuat, script dapat memperbesar target R melalui tradeRMultipliers. Misalnya macro strength tinggi dapat membuat target lebih jauh dibanding default.

Level Peran
SL Batas invalidasi trade. Jika kena sebelum TP, trade dihitung loss.
TP1 Partial profit pertama, dihitung 50% posisi dalam tracker.
TP2 Partial profit kedua, dihitung 25% posisi.
TP3 Target akhir, dihitung 25% posisi dan menutup trade tracking.

Contoh Hitung Risk

Contoh BUY dengan entry 2350.00
Entry = 2350.00
Stop Loss = 2345.00
Risk = 2350.00 - 2345.00 = 5.00 poin
TP1 1R = 2355.00
TP2 2R = 2360.00
TP3 3R = 2365.00

Jika TP1 kena, tracker menghitung 50% posisi sudah profit. Jika setelah TP1 harga turun dan stop kena, trade tidak selalu menjadi full loss karena sudah ada partial profit.

Contoh SELL dengan entry 2350.00
Entry = 2350.00
Stop Loss = 2356.00
Risk = 2356.00 - 2350.00 = 6.00 poin
TP1 1R = 2344.00
TP2 2R = 2338.00
TP3 3R = 2332.00

Untuk SELL, target berada di bawah entry dan stop berada di atas entry. Dashboard akan menampilkan live R, misalnya +0.45R jika harga sudah bergerak hampir setengah risk ke arah profit.

Contoh Membaca Dashboard

Dashboard menunjukkan BUY HUNT

Contoh teks: BUY HUNT | WAIT TRIG.

Artinya macro dan HTF sudah condong bullish, tetapi trigger entry belum muncul. Pada kondisi ini trader tidak perlu mengejar harga. Tunggu sweep, BOS, VWAP cross, pullback, OB tap, atau FVG mitigation.

Dashboard menunjukkan BUY ARMED

Contoh teks: BUY ARMED | B+.

Artinya setup BUY sudah lengkap secara logika, tetapi bisa saja masih menunggu candle close atau cooldown. Jika candle close dan tidak ada block, sinyal BUY bisa muncul.

Dashboard menunjukkan Manage

Contoh teks: BUY DRIVE +0.62R | GREEN FLOW+ | Q A.

Artinya posisi BUY aktif, trade sedang profit +0.62R, arah masih selaras, flow masih mendukung, dan kualitas setup tinggi. Next Action bisa menunjukkan RUN BUY atau MANAGE BUY.

Dashboard menunjukkan CUT/DEFEND

Contoh teks: SELL ALERT -0.28R | COUNTER FLOW-.

Artinya posisi SELL aktif, tetapi harga bergerak melawan posisi atau kondisi berbalik. Dashboard bisa menyarankan DEFEND SELL atau CUT SELL sebagai peringatan manajemen risiko.

Kelebihan

  • Menggabungkan macro driver dan price action, bukan hanya indikator teknikal.
  • Memakai multi-timeframe: M1, M5, M15, H1, H4.
  • Ada filter anti-whipsaw, anti-pucuk, dan fakeout divergence.
  • Dashboard sangat informatif untuk membaca alasan entry dan alasan no trade.
  • KNN menyimpan hasil trade historis sehingga indikator bisa menilai konteks yang mirip.
  • Risk level otomatis memudahkan evaluasi R-multiple.

Keterbatasan

  • Tidak ada alertcondition di script, jadi alert TradingView belum dibuat secara eksplisit.
  • Ini indikator, bukan strategy backtest resmi. Performance tracker internal tidak sama dengan backtest strategy TradingView.
  • KNN membutuhkan sample cukup banyak agar informasinya bermakna.
  • Data macro bergantung pada ketersediaan simbol TradingView seperti TVC:DXY, TVC:US02Y, dan TVC:US10Y.
  • Sinyal tetap bisa buruk saat spread melebar, news besar, data simbol lag, atau market sangat tidak normal.
  • Beberapa label di file asli terlihat memiliki karakter encoding rusak, tetapi logika script tetap bisa dijelaskan dari struktur kodenya.

Rekomendasi Penggunaan

  1. Gunakan pada XAUUSD M5 sesuai komentar script.
  2. Biarkan signalOnClose aktif untuk mengurangi sinyal prematur.
  3. Gunakan ALMA default jika fokus pada balance antara smooth dan responsif.
  4. Aktifkan resetKnn setelah mengganti MA type atau mengubah setting besar.
  5. Untuk pemula, gunakan KNN sebagai Advisory Only dulu sampai sample cukup.
  6. Perhatikan dashboard noTradeReason; sering kali alasan tidak entry lebih penting daripada sinyal entry.
  7. Hindari eksekusi buta saat dashboard menunjukkan KONFLIK HTF, KNN BLOCK, KC upper/lower, atau sesi tidak ideal.

Kesimpulan
